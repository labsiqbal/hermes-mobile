## Density contract
Use authored CSS density tokens for dimensions, spacing, icons and type, never document zoom or a whole-page transform. Text has a legibility floor, editable fields retain a 16px floor (mobile focus zoom), interactive targets retain 44px floors. Viewport bounds, breakpoints, borders and safe-area insets do not scale. Percentage is the requested density, not a promise to shrink every hit target below accessibility bounds. Browser accessibility zoom remains available.

## Implementation and review notes
- `appearance.ts` validates exact supported values, catches denied storage access and applies before React first paint. The old chat-only size is ignored (not multiplied into global density); erase removes both namespaced keys. A blocked write applies for the current session and is disclosed.
- `appearance.css` owns spacing/type tokens and independent icon scaling. Screen CSS and literal inline sizes consume the tokens. Borders, media breakpoints, viewport bounds and safe-area insets remain native. Editable fields use an explicit cascade safety invariant: screen `font` shorthands cannot shrink their 16px floor. Markdown code/table type has a 12px floor.
- Existing model catalog/search/reasoning/session-scoped handlers are unchanged. Only markup placement changed; attach/model/send/stop share the lower row, textarea spans the upper row. Workspace tools moved above transcript beside the existing header context. No microphone or navigation redesign.
- In-memory conversation scroll records now include density plus semantic block index/offset. Resume under a different density restores the reading block instead of obsolete raw pixels; identity, drafts, attachments and aliases use the unchanged scope. The mounted/hidden transcript also handles density events and multiline remeasurement. This is not durable message storage.
- Initial browser failures were retained: a raw-pixel anchor needed semantic remount restoration. Harness calibration corrected a stale detached DOM reference, fixture storage clearing and departure before native smooth scrolling settled. Expanded typography assertions then caught a genuine CSS cascade defect missed by target-box geometry alone; the final runner retains those assertions. No failed result is presented as live proof.
- Builder self-review: standards—shared token module, no dependencies/transport changes, existing seven lint warnings retained; spec—global root/detail/overlay scaling, persisted/reset/invalid/unavailable state and composer contracts verified below. Default independent review still owns acceptance; at most two default fix/review feedback cycles, then blocker escalation.
